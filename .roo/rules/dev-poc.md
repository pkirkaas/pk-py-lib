# Development/Proof of Concept Project

This is a development/Proof of Concept project, intended for rapid, experimental cycles.

It is NOT intended for production/enterprise/deployment at this point.

Therefore:

- DO focus on full documentation, edge cases, logging, etc 

- DO NOT focus on performance, production, scalability, team development issues.

- DO NOT focus on unit tests or testing framework.

## DB Schema Migration implementation

Since this is under rapid development/test cycles, DO NOT implement code to migrate DB settings/configuration changes yet. If the schema/settings structures change or there are any incompatibilities with the existing DBs/Settings, it is OK to wipe the existing DBs/configs & start afresh.
