# KDC Image Organizer (img-app) Project Specification

This describes the desired features/behavior/functionality of the img-app application to be developed/implemented.

The application is a desktop GUI application for individual users desktop computer to organize/sort/filter tens of thousands of image files/photographs stored on the local file system/disk. 

The application should use the pk-py-lib re-usable library of components, widgets & utilities also implemented in this project.

The first feature to be implemented is a similar image finder.
